# ADStudyHelper 작업 기록

## 2026-10-23 — 공부 캘린더·Google 백업 변경 정리

이번 기록은 이미 작성되어 있던 미커밋 구현을 확인하고 문서를 갱신한 과정입니다. 구현의 최초 작성 날짜는 이 기록으로 단정하지 않습니다.

### 변경 내용

- 월별 공부 캘린더와 날짜별 집중 시간·티어·RP·목표 진행률·학습 이벤트 화면 추가.
- 학습 상태 확정 시 완료·복습·가져오기 이벤트 기록, 새 날짜의 요약 생성, 기존 집중 시간 보존.
- Google 데스크톱 OAuth 및 PKCE·state·루프백 콜백 처리, OS 암호화를 이용한 로컬 토큰 저장.
- Drive 앱 전용 공간에 설치별 백업 파일 저장, 5분 간격 자동 백업 및 수동 백업.
- 다른 PC의 백업 변경 감지 시 사용자 선택 대기, 미리보기·버전 확인·로컬 사본 생성 후 복원.
- 백업에 공부 데이터만 포함하고 설정·로그인·페어링 토큰은 제외.
- 기존 포터블 EXE 삭제 반영. 이번 작업에서 새 EXE를 빌드하지 않음.

### 작업 과정

1. Git 상태·현재 브랜치·원격 저장소와 스테이징된 13개 파일의 변경을 확인했습니다.
2. 캘린더·백업 모듈, store·IPC·렌더러 연결 및 신규 테스트를 확인했습니다.
3. README에 사용법·파일 구조·문서 링크를 추가하고, HANDOFF의 이전 브랜치·파일명·검증 정보를 현재 상태로 정리했습니다.
4. CONTRACTS에 캘린더·백업 데이터와 IPC 계약을 추가하고 시각적 변경 기록에 기능 흐름을 추가했습니다.
5. 아래 자동 검증을 실행했습니다. 소스 수정이나 새 패키징은 수행하지 않았습니다.

### 검증 결과

- `npm test`: 211개 통과, 실패·취소·건너뜀 0개. 신규 Google 백업 14개와 공부 캘린더 10개 테스트 포함.
- `npm run check`: 종료 코드 0. package.json에 등록된 기존 메인 모듈 로드 검사입니다. 신규 캘린더·백업 모듈은 단위 테스트에서 로드했습니다.
- `git diff --check`, `git diff --cached --check`: 공백 오류 없음.
- 실제 Google 계정과 Drive 서버 검증은 수행하지 않았습니다. Google 테스트는 모의 네트워크·저장소를 사용하며 루프백 OAuth 테스트는 로컬 HTTP를 사용합니다.
- Electron GUI 조작, 포터블 빌드, Mac/Xcode 및 iPhone 기기 검증은 수행하지 않았습니다.
