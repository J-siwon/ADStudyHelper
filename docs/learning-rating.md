# 학습 RP와 복습 밸런스

학습 RP는 챕터나 공통 단계가 아니라 각 학습 목표에 귀속된다. 목표를 처음 달성할 때 기본 RP를 얻고, 이후 목표별 복습 상태가 유효 RP를 결정한다.

## 기본 규칙

- 목표 난이도: 기본 10 RP, 응용 20 RP, 심화 30 RP
- 복습: 목표 달성 후 직전 정답일 기준 1일, 3일, 7일, 30일
- 복습 판정: 정답 100%, 부분정답 75%, 오답 또는 기한 초과 50%
- 기습 질문: 30일 복습을 통과한 목표 중 매주 최대 7개
- 챌린저: 모든 목표 달성 및 복습 페널티가 없는 100% 유효 RP

현재 카탈로그 기본 분류는 기본 20개, 응용 151개, 심화 29개이며 최대 RP는 4,090이다. 목표 설명이나 난이도 분류가 바뀌면 최대 RP와 비율 기반 티어 경계도 자동으로 다시 계산된다.

기본 티어 시작점은 브론즈 0%, 실버 8%, 골드 20%, 플레티넘 38%, 다이아 62%, 마스터 90%, 챌린저 100%다. 브론즈부터 다이아까지는 각 구간을 같은 폭의 5단계(5→1)로 나누며 마스터와 챌린저는 세부 티어가 없다. 챌린저 상태에서 복습 페널티가 생기면 마스터로 내려가고, 해당 목표를 다시 맞히면 유효 RP가 복구된다.

## 밸런스 적용

1. 개발 체크아웃에서는 `config/learning-rating.json`을 수정한다.
2. 포터블 배포물에서는 EXE 옆의 `learning-rating.json`을 수정한다.
3. `apply-learning-balance.bat`을 실행한다.
4. 성공 메시지를 확인하고 ADStudyHelper를 재시작한다.

BAT는 설정을 `%APPDATA%\ADStudyHelper\learning-rating.json`으로 복사한다. 앱은 시작할 때 전체 설정을 다시 검증하며, 잘못된 설정은 적용하지 않고 내장 기본값을 사용한다.

조정 가능한 값은 목표 난이도별 RP, 티어 시작 비율, 세부 티어 수, 복습 판정 배율, 복습 간격, 주간 기습 질문 수다.
