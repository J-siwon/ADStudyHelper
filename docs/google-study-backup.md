# 공부 캘린더와 Google Drive 백업

사이드바의 **공부 캘린더**에서 월별 집중 시간과 날짜별 학습 기록을 확인할 수 있습니다. 공부 시간은 기존 WORK 상태에서 누적한 시간입니다. 진행률은 완료 목표 수 / 전체 목표 수이며 티어·RP와 별도로 표시합니다.

날짜는 PC의 현지 날짜를 사용합니다. 티어·RP·진행률은 그 날짜에 앱에서 마지막으로 기록한 값입니다. 앱을 사용하지 않은 날짜의 값을 추정하지 않습니다. 기능 추가 이전의 집중 시간은 보존하며, 과거의 티어와 상세 학습 내역은 기록 없음으로 표시합니다. 완료와 복습, 학습 가져오기는 앱에서 확정했을 때 기록됩니다.

## 본인 Google 계정 연결 준비

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들거나 선택합니다.
2. 프로젝트에서 **Google Drive API**를 사용 설정합니다.
3. Google Auth Platform에서 앱 이름과 연락처를 설정하고, 대상 사용자를 External / Testing으로 설정한 뒤 본인 계정을 테스트 사용자에 추가합니다.
4. 데이터 액세스에 `openid`, 이메일, `https://www.googleapis.com/auth/drive.appdata` 범위를 설정합니다.
5. OAuth 클라이언트를 **Desktop app(데스크톱 앱)** 유형으로 만들고 JSON 파일을 다운로드합니다. 웹 앱용 클라이언트는 사용할 수 없습니다.
6. 앱의 공부 캘린더에서 **로그인 설정 파일 선택**으로 이 JSON 파일을 선택하고 **Google 계정 연결**을 누릅니다. 시스템 브라우저에서 로그인하고 Drive 저장 권한을 허용합니다. 앱은 임시 포트의 `127.0.0.1` 콜백을 사용합니다.

설정 JSON을 Git에 커밋하거나 공부 백업에 넣지 마세요. 설정과 OS 암호화된 로그인 토큰은 로컬에 보관합니다. 렌더러에는 토큰을 전달하지 않습니다. 새 PC에서도 동일한 Google Cloud 프로젝트의 동일한 데스크톱 클라이언트 설정을 사용해야 기존 앱 전용 데이터를 찾을 수 있습니다.

Google의 **Testing** 상태에서는 이번 Drive 권한을 포함한 refresh token이 7일 후 만료될 수 있습니다. 앱에서 재연결 안내가 나오면 연결을 해제한 뒤 다시 로그인하세요. 다른 사용자에게 배포하기 전에는 OAuth 게시 상태와 필요한 검증을 별도로 준비합니다. [Google OAuth 공식 문서](https://developers.google.com/identity/protocols/oauth2)

## 백업과 복원

- 연결 후 변경된 기록을 최대 5분 간격으로 자동 백업합니다. 종료 직전 변경을 즉시 보관하려면 **지금 백업**을 누르세요.
- 공부 시간, 일별 요약·학습 내역, 전체 학습 상태를 저장합니다. 화이트리스트, 알림 비밀키, iPhone 페어링 토큰, Google 로그인 토큰은 포함하지 않습니다.
- 파일은 Google Drive의 앱 전용 숨김 폴더에 저장되어 일반 Drive 화면에는 표시되지 않습니다. 각 PC가 자기 파일 하나를 관리하며, 복원할 때는 가장 최근 수정된 파일을 불러옵니다.
- 처음 연결했을 때 기존 백업이 있으면 자동 업로드를 멈춥니다. **백업 불러오기**로 기존 기록을 복원하거나 **현재 PC 기록으로 백업**을 선택하세요. 다른 PC가 새로운 백업을 올렸을 때도 같은 선택이 필요합니다. 여러 PC 기록을 자동으로 합치지는 않습니다.
- 복원은 날짜 범위와 공부량·학습 요약을 먼저 보여줍니다. 확인한 뒤 적용하며, 취소하면 현재 기록을 유지합니다. 백업이 미리보기 이후 바뀌면 다시 불러와야 합니다.
- 복원 전에 로컬 저장 파일과 같은 폴더에 `study-before-restore-*.json` 사본을 만듭니다. 일반 Windows 설치에서는 `%APPDATA%\ADStudyHelper`입니다. 사본에는 공부 기록과 학습 상태만 들어 있습니다. 복원 완료 후 화면을 새로 불러옵니다.
- 인터넷 연결이나 Google 요청이 실패하면 로컬 공부 기록을 유지하며 다음 백업 주기에 재시도합니다. 연결 해제는 로컬 로그인 토큰을 삭제하고 자동 백업을 중단합니다. 원격 백업은 보존합니다.

Google Drive에서 앱 데이터를 직접 삭제하거나 앱을 제거하면 원격 기록을 잃을 수 있습니다. [앱 전용 저장 공간 공식 문서](https://developers.google.com/workspace/drive/api/guides/appdata)
