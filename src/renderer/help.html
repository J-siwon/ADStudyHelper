ADStudyHelper 사용 방법

ADHD 사용자를 위한 집중력 향상 데스크톱 앱 · 이 창은 언제든 대시보드의 ❓ 도움말 버튼으로 다시 열 수 있어요.

1. 한눈에 보기

앱은 지금 무엇을 하고 있는지(활성 창·브라우저 URL)를 2초마다 확인해서 WORK(집중) 또는 BREAK(휴식) 상태로 판정합니다.

  • WORK일 때만 "오늘 집중 시간" 타이머가 올라갑니다.
  • BREAK가 연속 10분(기본값)을 넘기면 코딩 펫이 방방 뛰며 "다시 집중!"이라고 알려줍니다.
🔶 코딩 펫 — 화면 구석에 떠 있는 작은 펫이 내 집중 상태와 Claude Code/Codex 작업 상태를 함께 보여줍니다. 동시에 여러 세션이 작업하면 그 수만큼 노트북이 표시됩니다:
  • 집중 중 + 코딩 에이전트 작업 중 → 코딩하는 모습 💻
  • 집중 중 + 코딩 에이전트 대기 → 공부하는 모습 📖
  • 휴식 중 + 코딩 에이전트 작업 중 → 컴퓨터 앞에서 자는 모습 😴💻
  • 휴식 중 + 코딩 에이전트 대기 → 자는 모습 😴
  • 쉬는 시간 제한 초과 → 방방 뛰며 알림 🦘
드래그로 옮길 수 있고, 고급 설정에서 끌 수 있습니다. (Claude Code/Codex 훅이 작업 상태를 로컬 서버에 알려주며, 신호가 끊기면 3분 뒤 자동으로 대기로 돌아갑니다.)

2. 화면 구성

상단 배지 — 현재 WORK/BREAK 상태, 크롬 확장 연결 여부(확장 연결됨/확장 미연결), 그리고 웹캠 상태(웹캠 꺼짐/웹캠 연결됨/웹캠 미연결)를 표시합니다.

오늘 집중 시간 — 오늘 누적된 집중(WORK) 시간입니다. 자정이 지나면 자동으로 0부터 다시 셉니다. (앱을 껐다 켜도 그날 누적은 유지됩니다.)

쉬는 시간 — 휴식(BREAK) 동안 누적되며, 잠깐 작업으로 돌아가도 바로 0이 되지 않고 유지됩니다. 연속 10분 집중(WORK)을 유지해야 0으로 초기화됩니다. (짧은 딴짓·복귀를 반복해도 누적 휴식이 보존됩니다.)

집중 판정 목록 — 어떤 앱/사이트를 집중으로 볼지 직접 정합니다. (3번 항목)

고급 설정 — 카메라 추적, 폰 알림 등 선택 기능입니다. (4~6번 항목)

3. 집중 판정 목록 설정 (핵심)

허용 앱

여기 적힌 키워드가 현재 활성 프로그램 이름에 포함되면 항상 WORK로 인정합니다. 한 줄에 하나씩 적으세요.

이름을 모를 땐? 대시보드 타이머 아래 "현재 활성: …" 줄에 지금 보고 있는 앱 이름이 그대로 표시됩니다. 그 이름의 일부를 키워드로 넣으면 됩니다.
예) VS Code는 Visual Studio Code로 잡히므로 Code만 넣으면 매칭 · 터미널은 Windows Terminal Host이므로 Terminal · 메모장은 Notepad.exe이므로 Notepad.

URL 판정 방식 — 허용 목록 vs 제한 목록

브라우저(크롬)를 보고 있을 때 어떤 사이트를 집중으로 볼지 두 가지 방식 중 선택할 수 있습니다. 대시보드의 URL 판정 방식 드롭다운에서 고르세요.

✅ 허용 목록 (allow)

"이 사이트들만 공부다"

  • 목록에 있는 URL → WORK
  • 그 외 모든 사이트 → BREAK
  • 확장 미연결이면 → BREAK

예: docs.google.com, github.com, *.namu.wiki 같은 학습 사이트만 등록.

⛔ 제한 목록 (block)

"이 사이트들만 딴짓이다"

  • 목록에 있는 URL → BREAK
  • 그 외 모든 사이트 → WORK
  • 확장 미연결이면 → WORK

예: youtube.com, instagram.com, facebook.com/* 같은 방해 사이트만 등록.

어떤 걸 고를까요?
· 공부할 사이트가 몇 개로 정해져 있다 → 허용 목록(엄격, 집중에 좋음)
· 평소엔 자유롭게 쓰되 특정 딴짓 사이트만 막고 싶다 → 제한 목록(관대)

URL 패턴 작성법

  • 부분 문자열로 매칭됩니다. github.com 은 https://github.com/... 전체에 매칭됩니다.
  • 와일드카드 * 사용 가능. 예: google.com/*, *.tistory.com
  • 한 줄에 하나씩 입력합니다.

목록을 수정한 뒤 저장 버튼을 꼭 눌러주세요.

4. 크롬 확장 연결 (URL 판정에 필요)

브라우저 URL을 읽으려면 함께 들어 있는 크롬 확장을 한 번 로드해야 합니다.

  1. 크롬에서 chrome://extensions 열기
  2. 오른쪽 위 개발자 모드 켜기
  3. 압축 해제된 확장 프로그램 로드 클릭
  4. 앱 폴더 안의 chrome-extension 폴더 선택
  5. 대시보드 배지가 확장 연결됨으로 바뀌면 성공

확장을 연결하지 않으면 허용 목록 모드에서는 크롬이 항상 BREAK로 잡힙니다.

5. 웹캠 시선 추적 (선택)

카메라로 얼굴/시선을 확인해, 자리에 없거나 화면을 안 보면 BREAK로 강제합니다. (기본 꺼짐 — 프라이버시 보호)

  • 고급 설정 → 웹캠 시선 추적 토글을 켜고 카메라 권한을 허용하세요. 카메라 미리보기 창이 떠서 얼굴이 잘 인식되는지(초록 점)와 시선 이탈 여부를 보여줍니다.
  • MediaPipe가 얼굴·눈동자(iris)를 인식해, 시선이 화면을 많이 벗어나면 휴식(BREAK)으로 간주합니다. (오프라인 동작)
  • 카메라 소스: 내장 웹캠 또는 폰 스트림(휴대폰 MJPEG URL) 선택.
  • 카메라/폰이 실제로 연결되지 않으면 BREAK를 강제하지 않고 크롬 확장 판정으로 자동 폴백합니다.
  • 연결 상태는 상단 웹캠 배지로 확인할 수 있습니다 — 웹캠 연결됨(초록)이면 카메라 신호 수신 중, 웹캠 미연결(주황)이면 권한 거부·스트림 오류 등으로 신호가 없는 상태입니다.
  • 미리보기 창은 ✕로 닫아도 카메라 인식은 계속 동작합니다(백그라운드). 다시 보려면 대시보드의 📷 미리보기 버튼을 누르세요.

6. 자리 비움 → 폰 알림 (선택)

오래 자리를 비우면 스마트폰으로 푸시 알림을 보냅니다.

  1. 휴대폰에 ntfy 앱 설치 (Android/iOS 무료)
  2. 앱에서 원하는 토픽 이름 구독 (예: my-study-alert)
  3. 대시보드 ntfy 토픽에 같은 이름을 입력하고 저장
  4. 자리 비움이 임계값(자리 비움 알림(분))을 넘으면 폰으로 알림 도착

폰 쉬는시간 등록: 대시보드의 폰 제어 주소(예: http://192.168.0.x:47616)를 같은 와이파이의 폰 브라우저로 열고 "쉬는시간 등록"을 누르면, 그 동안 자리 비움 알림이 억제됩니다.

8. 자주 묻는 질문

타이머가 안 올라가요

상태 배지가 BREAK인지 확인하세요. WORK일 때만 시간이 쌓입니다. 크롬을 보고 있다면 확장 연결 여부와 URL 판정 방식/목록을 점검하세요.

처음 실행할 때 파란 경고창이 떠요

코드 서명이 없는 앱이라 Windows SmartScreen 경고가 나올 수 있습니다. 추가 정보 → 실행을 누르면 됩니다. (정상)

펫 알림이 너무 늦게/일찍 떠요

BREAK 연속 임계값은 기본 10분입니다. 테스트용으로 짧게 보려면 앱을 환경변수와 함께 실행하세요: FOCUS_BREAK_SEC=5

이 창을 닫으려면 상단의 닫기(×) 버튼을 누르세요.
